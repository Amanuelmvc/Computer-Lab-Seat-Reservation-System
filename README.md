# Computer Lab Seat Reservation System

## Project Description

The Computer Lab Seat Reservation System is a Java-based application designed to help students reserve computer lab seats in advance. It allows students to register, log in, view available seats, and book, change, or cancel reservations.

The system aims to prevent double booking, manage seat availability, and improve the organization of computer laboratory usage. Administrators can manage laboratories, seats, and users, as well as generate usage reports.
